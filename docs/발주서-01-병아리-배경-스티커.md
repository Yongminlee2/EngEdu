발주자: Claude (앱 통합 담당) / 제작자: Codex (이미지 생성 담당)
목적: 앱의 벡터 병아리·이모지를 진짜 일러스트로 교체한다 (듀오링고급 귀염뽀짝).

## 공통 스타일 (모든 이미지에 적용)

- 대상: 유치원~성인이 함께 쓰는 학습 앱. **동글동글, 스티커 느낌, 두꺼운 어두운 갈색(#4E342E) 외곽선**
- 병아리 캐릭터 고정 규격: 몸 노란색 **#FFD54F**, 부리·다리 주황 **#FF8A50**, 볼터치 연한 분홍,
  눈은 크고 까맣게(흰 하이라이트 점), 머리에 작은 깃털 한 가닥. **모든 포즈에서 같은 캐릭터로 보여야 한다**
- 배경 완전 투명 PNG (배너만 불투명)
- 그림자·그라데이션 최소, 플랫 셀 채색
