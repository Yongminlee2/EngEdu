# 삐약공부 → 삐약영어 + 삐약수학 분리 설계

2026-07-31. 한 앱(삐약공부)에 들어 있던 영어·수학을 **독립 앱 2개**로 나눈다.

## 왜 나누나 (사용자가 밝힌 이유 3가지)

1. 홈 화면에서 아이콘을 눌러 **바로 그 과목으로** 들어가고 싶다 (과목 선택 대문 생략)
2. 한 앱에 다 들어 있으니 **무겁고 복잡해** 보인다
3. 앞으로 영어와 수학을 **따로 발전**시키고 싶다

세 가지를 모두 만족하는 것은 완전 분리뿐이다. 아이콘 2개만 만드는 안(activity-alias)은
3번을 못 하고, 멀티모듈 안은 저장소가 안 나뉘고 구조만 복잡해져 기각했다.

## 확정 결정 사항

- **완전 분리**: 저장소 2개, 코드 복제 후 각자 다이어트. 공용 코드(소리·DB·드래그판)의
  버그는 앞으로 **두 저장소에 각각** 고친다 — 감수하기로 결정
- **지갑·하트·스트릭은 앱마다 따로.** 기존 250원은 삐약영어에 남는다
- **수학 진행도는 새로 시작.** 이사 도구는 만들지 않는다 (레벨테스트만 다시)
- **연습장(필기 오버레이)은 수학 쪽에만** 남긴다 (원래 수학용으로 만든 기능)
- **영어 앱 DB 의 수학 기록은 지우지 않고 무시한다** (사용자 데이터 삭제는 하지 않는다)
- 삐약수학 원격 저장소는 나중에 사용자가 만들어 준다 — 그때까지 **로컬 git 에만 커밋**

| 항목 | 결정 |

## 데이터 흐름

- 삐약영어: 기존 `piyak.db` 그대로 사용. 수학 기록(progress 의 math_* 행, 수학 skills 행)은
  화면에서 참조하지 않으므로 그냥 남는다. 마이그레이션 없음.
- 삐약수학: 새 패키지라 빈 DB 에서 시작. Db 스키마는 그대로 복제한다 (letters 테이블 등
  영어용 테이블이 남지만 무해 — 스키마를 건드리면 DbMigrationTest 류의 함정만 늘어난다).

## 오류 처리

- 두 앱 모두 크래시 기록기(PiyakApp) 유지 — 설정 → 🐞 로 오류를 꺼내 볼 수 있다
- 삐약영어 업데이트 설치는 반드시 `install -r` (제거 후 설치하면 데이터가 날아간다)

## 검증

- 양쪽 각각 단위테스트 통과: 영어 쪽은 수학 테스트(MathTest, InteractionTest 수학 부분,
  PlacementSubjectTest 수학 부분) 제거, 수학 쪽은 영어 테스트(GraderTest 영어 부분,
  LettersTest, LetterStrokeTest 등) 제거. 콘텐츠 검사 테스트는 각자 남은 팩 기준으로 조정
- 양쪽 APK 빌드 성공
- **삐약영어 설치 후 250원·알파벳 기록·영어 진행도가 그대로인지** (가장 중요)
- 삐약수학 설치 후 레벨테스트 → 수학 레슨 → 코인 적립 동작
- 폰 홈 화면에서 두 아이콘이 구분되는지

## 하지 않는 것 (YAGNI)

- 수학 진행도 이사 도구 (새로 시작으로 결정)
- 두 앱 간 지갑 동기화 (앱마다 따로로 결정)
- 공용 코드의 라이브러리화·서브모듈 (개인 프로젝트에 과함, 복제로 감수)
