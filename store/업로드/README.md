# 업로드 폴더 — 플레이 콘솔에 그대로 올리는 것들

| 파일 | 콘솔 어디에 | 규격 |
|---|---|---|
| `app-release.aab` | 프로덕션 → 새 버전 만들기 → App Bundle | — |
| `icon_512.png` | 스토어 등록정보 → 앱 아이콘 | 512×512 PNG, 알파 없음 |
| `feature_graphic.png` | 스토어 등록정보 → 그래픽 이미지 | 1024×500 |
| `스크린샷/<언어>/*.png` | 스토어 등록정보 → 언어 고른 뒤 → 휴대전화 스크린샷 | 최소 2장 |

## 스크린샷 순서

1. `01_home` — 홈. 배너·병아리·학습 코스
2. `02_skills` — 실력 대시보드와 지갑
3. `03_wallet` — 용돈 지갑과 상점
4. `04_stats` — 통계 달력
5. `05_badges` — 배지
6. `06_question` — 문제 화면 (그림 있는 4지선다)
7. `07_answer` — 정답 해설 패널

폴더 이름은 콘솔 언어 코드와 맞춰 두었다.

| 폴더 | 콘솔 언어 |
|---|---|
| `ko` | 한국어 |
| `en` | 영어(미국) ← 기본 언어 |
| `ja` | 일본어 |
| `zh` | 중국어(간체) |
| `zh_Hant` | 중국어(번체) |
| `zh_HK` | 중국어(홍콩) |
| `es` `fr` `de` `pt` `ru` `th` `vi` `id` | 스페인·프랑스·독일·포르투갈·러시아·태국·베트남·인도네시아어 |

## 다시 만들려면

```bash
# 폰 연결 후
python tool/shoot_all_langs.py          # 14개 언어 촬영 (원본은 store/screenshots/)
python tool/prep_screenshots.py         # 상태바·내비바 자르고 여기로. 원본은 지운다
```

아이콘과 그래픽 이미지는 앱의 실제 어댑티브 아이콘과 배너에서 합성한 것이다.
